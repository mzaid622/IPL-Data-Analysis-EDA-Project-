# IPL Data Analysis (EDA Project)

## 📌 Project Overview
This project is an **Exploratory Data Analysis (EDA)** on Indian Premier League (IPL) data.  
The goal is to analyze match outcomes, player performances, and team statistics using **Python (Pandas, NumPy, Matplotlib, Seaborn)**.

## 📂 Dataset
- File: `IPL.csv`  
- Contains match-level data such as:
  - Match date, venue, and teams
  - Toss results and decisions
  - First and second innings scores
  - Match winners and margins
  - Player of the match, top scorers, and best bowlers

## ⚙️ Tech Stack
- **Python**
- **Pandas** – Data manipulation
- **NumPy** – Numerical operations
- **Matplotlib / Seaborn** – Data visualization
- **Jupyter Notebook** – Analysis & presentation

## 📊 Key Analysis Performed
- Team-wise and player-wise performance analysis
- Toss decisions vs match outcomes
- Winning patterns (by runs vs wickets)
- Top scorers and best bowlers distribution
- Venue-wise performance trends

## 🔍 Insights (examples)
- Teams chasing had a higher win probability in certain venues.
- Some players consistently performed as “match winners.”
- Toss decisions often influenced match results, especially in Mumbai venues.
